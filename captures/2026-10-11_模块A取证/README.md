## 为什么 40.52 判不了黑电平

曲线（`isp_gamma.v` 内联表 = `gamma_lut_twoseg_p160_a050.hex`，`x<=160: y = 160·(x/160)^0.5`）
反推：`x = 160 × (40.52/160)² = 10.26`（8bit，曲线输入端）。

能产生"曲线输入 ≈ 10"的组合有**两个**：

- BLC **旁路** + 曲线开，基座 raw10 = **41**（`41>>2 = 10` → `gamma[10] = 40`）
- BLC **启用**(BL=56) + 曲线开，基座 raw10 = **94…97**（`(95-56+2)>>2 = 10`）

⇒ 单凭这张图分辨不出 40.5 是"旁路时的基座"还是"扣完之后仍剩的漏光"。

**但两个世界里把 `BLACK_LEVEL` 改小到 42 都不能让 40.5 变黑**：

- 世界 A（旁路）：BLC 不在通路上，改常数**零作用**；
- 世界 B（启用，基座 ≈95）：`(95-42+2)>>2 = 13` → `160·√(13/160) = 45.6`，**反而更亮 5 码**。
