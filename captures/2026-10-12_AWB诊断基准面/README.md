## 为什么这张图是决定性的
1. 帧内只有一种表面。2 百万像素。灰世界 AWB 的定义就是把整帧均值 R/G、B/G 拉到 1.000。
   对这种画面，它理论上必须精确等于 1.000——实测 0.9295。
   ⇒ **AWB 没有达到它自己的目标**，而且是在最容易的输入下。
2. R-G = -3.157、B-G = -3.015，与之前 4 次测量（-2.55 / -2.61 / -3.17 / -2.58）一致。
   这是第 5 次独立复现同一个常数。
3. 同一张图里的 logo 主色读作 (27,44,75)x5784 与 (235,29,36)x1505，
   与 ROM 常量 (28,45,78)/(237,28,36) 逐码一致 ⇒ 采集链在该电平不接近 R-G 缺口。
4. 缺口与传感器增益无关：15.75x 与 31.5x 两档下 R-G 分别是 -2.608 / -2.547。
   ⇒ 缺口是加在传感器增益级**之后**的。
