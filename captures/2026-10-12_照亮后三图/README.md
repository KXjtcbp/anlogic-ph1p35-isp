## 三条被证实的结论
1. **Gamma 曲线在通路里、表就是 K=45 那张**：把 10 的每个分位数过表预测 11 ——
   p1 +4 / p5 +3 / p10 +3 / p25 +0 / p50 +1 / p75 -2 / p90 -1 / p95 +0 / p99 +8，
   均值 58.01 -> 预测 68.91 / 实测 69.28（差 +0.38）。
2. **数字增益 x2 确实在生效**：11（31.5x）p50=60、p90=130；12（15.75x）p50=32、p90=82。
   去掉曲线压缩后的理论比约 1.7~1.8，实测 p90 比 1.585、p95 比 1.544、p50 比 1.875。
   再验一遍：LUT[10 的 p90 / 2] = LUT[61] = 82 = 12 的实测 p90（完全命中）。
3. **采集链仍是 identity**：三张的 logo 主色都读作 (27,44,75) x5784 与 (235,29,36) x1505，
   与 `captures/2026-10-11_链校准后` 那批逐码一致。

★关键：R-G 与 B-G 在 Y 均值 41 ~ 69 之间**基本不变（-2.6 ~ -3.2 码）**★，
02:02 那张暗图（Y=20.4）也是 **-2.575**。
=> 偏色不是"增益不够"（那会随亮度成比例变化），而是**一个与亮度无关的固定加性偏置**：
   R 比 G 低约 3 码、B 比 G 低约 3 码。
   这解释了为什么"越暗越绿"——同样的 3 码在 Y=20 时是 15%，在 Y=60 时只剩 5%。
