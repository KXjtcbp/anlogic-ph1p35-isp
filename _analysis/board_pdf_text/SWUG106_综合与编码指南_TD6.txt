1 概述 
本文档主要介绍了 TangDynasty®（以下简称 TD 软件）软件中综合技术和硬件描述语言 （HDL）的
设计编码规范，包括可综合的HDL 代码、TD 支持的Synthesis Directive 、TD 综合编译选项、典型应
用示例、面积优化、 时序优化、 功耗优化方法。通过此文档， 可帮助用户在设计过程中规避不必要的综
合问题，并充分利用TD 软件的体系结构功能。 
2 HDL 编码支持 
本章主要介绍 了 TD 软件中 对 HDL 设计编码的支持 程度 ，帮助 用户了解 Verilog、VHDL、
SystemVerilog 相关语法知识。

2.1.6 描述语句支持 
2.1.6.1 if条件分支 
在always 块中，如果出现if（else if）（else）条件分支，会综合出（多个）2 选 1 多路选择器
逻辑。如果有很多else if，则会出现多层2 选1 多路选择器链（树） 。 
 
另一种写法是逆序全 if，利用多重过程赋值时，只有最后赋值语句生效的特性，从而得到等价的
逻辑。 
wire [3:0] cond; 
wire [4:0] din; 
reg dout; 
always @(*) 
if (cond[0]) 
  dout <= din[0]; 
 else if (cond[1]) 
  dout <= din[1]; 
 else if (cond[2]) 
  dout <= din[2]; 
 else if (cond[3]) 
  dout <= din[3]; 
 else 
  dout <= din[4];

2.1.6.2 case条件分支 
case 语句： 
case 语句通常执行变量、常数与表达式间的比较，并选择几个并行分支中的一个。选择条件通常
为按照分支顺序依次判断其真假，并执行第一个判断为 true 的分支。如果没有一个分支匹配，则执行
默认分支。对于某组信号的不同值作为分支条件可以用case 语句描述。 
 
casex/casez 语句： 
casex/casez 语句对于case 语句存在分支操作相同， 条件相仿的共同点，区别为：casez 将分支选
项中任意位的所有 z 值视为不关心；casex 将分支选项中任意位的所有x、z 和？值视为不关心。使用
casez 或casex 可以简化代码，增加可读性。 
wire [3:0] cond; 
wire [4:0] din; 
reg dout; 
always @(*) 
 dout <= din[4]; 
 if (cond[3]) 
  dout <= din[3];  
if (cond[2]) 
  dout <= din[2]; 
if (cond[1]) 
  dout <= din[1]; 
if (cond[0]) 
  dout <= din[0];   
wire [2:0] sel; 
wire [4:0] din; 
reg dout; 
always @(*) 
 case (sel) 
  3'b000: dout <= din[0]; 
  3'b001: dout <= din[1]; 
  3'b010: dout <= din[2]; 
  3'b011: dout <= din[3]; 
  default: dout <= din[4]; 
 endcase

module mult_8b_while(a, b, q); 
  parameter bsize = 8; 
  input  [bsize-1 : 0] a, b; 
  output [2*bsize-1 : 0] q; 
  reg [2*bsize-1 : 0] q, a_t; 
  reg [bsize-1 : 0] b_t; 
  reg [bsize-1 : 0] cnt; 
  always @(a or b) begin 
    q = 0; 
    a_t = a; 
     b_t = b; 
     cnt = bsize; 
     while(cnt > 0) begin 
       if (b_t[0]) begin 
          q = q + a_t;     
      end 
      else begin 
          q = q; 
      end 
      cnt = cnt - 1; 
     a_t = a_t << 1; 
     b_t = b_t >> 1;  
     end 
end 
endmodule

4.2.20 bound 
功能说明：在物理实现（physical implementation）阶段，用户可以指定器件布局的区域约束，
简单的说， 就是限制指定的一组器件只可以放置在指定的区域内。 区域约束常用于保留之前的芯片设计
的性能，或者是为芯片布局作平面规划（floorplanning）。 
TD 支持三种不同类型的区域约束：auto，floating 和 fixed。 
auto 类型允许软件自动决定布局区域，尽力将指定的一组器件放置在相互临近的位置。用户可以
指定软件处理该auto 类型区域约束的约束级别(effort level):low, medium 和 high。 
floating 类型的区域约束，用户需要给定矩形区域的大小:width 和 height,由软件自动决定布局
的位置，并将指定的器件组放置在该矩形区域内。 
fixed 类型的区域约束， 用户需要给定矩形区域的大小(width 和 height)和位置(origin， 即矩形
左下角坐标)，软件将指定的器件组放置在该矩形区域内。另外，用户可以指定免约束的器件类型
(excluded types)， 对指定的器件组中的某些类型的器件不做区域约束。 缺省情况下， 如果空间允许的
话，指定的器件组外的其他器件也可以放置在给定区域内;用户如果为了保留可用的布线空间，可以设
置区域约束为reserved，即不允许指定器件外的其他器件放置在该区域内。 
使用场景：在adc 内使用，不能在HDL 内描述，用户通过给定矩形区域的大小（width 和height）
和位置（origin）指定器件放置位置。 
adc 示例：

add_cells_to_bound –bound bound0 –cells inst_name

定的cell 下的所有instance 都加入这个bound。

5.2 组合逻辑 
在数字电路中，根据逻辑的区别，数字电路可以分成两大类，一类叫做组合逻辑电路、 另一类叫做
时序逻辑电路。组合逻辑电路在逻辑功能上的特点是任意时刻的输出仅仅取决于该时刻的输入， 与电路
原来的状态无关。因此组合逻辑是新值只依赖输入相关的值。

程块中。

5.2.5 避免不稳定组合逻辑环 
与稳定组合逻辑环相比，不稳定的组合逻辑环输出值会出现 0、1 跳变，即，当设计出不稳定的组
合逻辑时， 电路中的信号会在特定的状态下进入振荡状态。不稳定组合逻辑环违反了电路设计中的同步
原则，从而导致设计的电路出现大量问题，包括：信号不稳定，出现反复振荡，造成电路大功率消耗；
产生毛刺；时序违规等。 不稳定组合逻辑环会造成设计系统极不稳定， 因此在设计中要避免不稳定组合
逻辑环的构造。

5.11.4 按编码方式分类 
FSM 有限状态机除按照输入输出关系分类外， 还可以采用编码方式进行分类。最著名的是二进制编
码，除此之外还有格雷编码和one-hot 编码。 
5.11.4.1 二进制编码 
顺序二进制编码，即将状态依次编码为顺序的二进制数。顺序二进制编码是最紧密的编码。 
优点：在于它使用的状态向量位数最少。例如对于6 个状态的状态机，只需要 3 位二进制数来进
行编码，因此只需要 3 个触发器来实现，节约了逻辑资源。 
缺点：翻转次数较多，功耗大；易出现毛刺；状态跳转需要过多组合逻辑电路，电路复杂，不利于
级数的优化。 
 文件名：binary_fsm.v

5.11.4.2 one-hot编码 
One-Hot 编码， 又称为一位有效编码、 独热码，主要是采用N 位状态寄存器来对N 个状态进行编码，
每个状态都由他独立的寄存器位，并且在任意状态时候只有一位有效。 
优点： 译码简单，组合逻辑电路较少，电路可靠性较高； 状态跳转简单，译码速度和编码数量无直
接关系，系统运行速度较快。 
缺点：所消耗的寄存器是所有编码方式中最高的；采用独热编码会生成不可达到的多余状态。 
 文件名：onehot_fsm.v

6.1 面积优化 
6.1.1 信号优化 
对任意信号进行keep 操作后，综合时便不再对其进行优化，与之对应的，相同功能下电路面积会

添加 keep 综合指令，对应的常数信号会得到保留，因此电路面积会增大，当用户期望进行面积优
化时，便可去掉对应的keep 综合指令。

6.1.5 复用复位信号 
复位信号是指用来复位电路状态的信号， 可以将电路强制进入一个稳定的确定状态。复位时需要考
虑异步和同步复位方式，以及复位的recovery 和removal 等时序。 
 
在电路设计中复位信号控制的范围有大有小， 有的可以复位整个电路， 有的复位多个子模块， 有的
只重置一个计数器或状态机寄存器。 
Anlogic FPGA 硬件资源多个DFF 是共享同一套控制逻辑的，拥有相同的复位逻辑的DFF 才能被相
邻摆放。如果1 个DFF 的复位逻辑独一无二，那其它DFF 的位置将无法放与它相邻。 
一个良好的设计会尽可能重复使用复位信号， 这需要线网相同、 边沿类型相同、 同步异步类型也相
同。如果是多个时钟域， 请做好不同时钟复位桥， 功能上再各个时钟域的握手与时间同步， 在系统上需
整体考虑。 
如果两个寄存器分别用同步和异步来复位，那它们的控制逻辑不兼容，造成面积的损失。

6.2.4 反沿借半拍 
如果某个时序路径超出较少额度， 并且该时序路径上游的时序又保持很松弛的情况时，可以采用反
沿借半拍的方式改善时序。 
如果上下游2 个时序路径都是时钟上升沿采样(posedge)，上游时序松弛，但下游组合逻辑复杂难
以收敛，可以将他们的打拍寄存器改成下降沿采样(negedge)。通过该方法，上游时序路径变为0.5 个
时钟周期，通过采用set_multicycle_path 的方式，下游时序路径从1 时钟周期变成1.5 个时钟周期。 
同理， 如果上游紧张下游松驰时， 就可以把上游约束成1.5 个时钟周期； 如果上下游都是下降沿采
样时，便可采用将中间打拍寄存器改成上升沿采样的方式进行时序优化。 
默认情况下，STA 遇到中间有反沿时， 会把上下游全部按照0.5 个周期的约束进行时序分析。 因此，
在 HDL 中， 在时钟反沿后，还需要通过采用set_multicycle_path 的方式， 将SDC 中1.5 个周期的路径
约束成2 个周期。 
6.2.5 Retiming

存器往紧的一侧移动）改善时序收敛的难度。

6.2.10 大MUX语句优化 
大的case 语句或者索引取址语句会综合出大的MUX 逻辑，最后用LUT 来实现。一般可以认为一个
6 输入LUT 可以实现一个4 选 1 MUX，那16 选1 MUX 就需要2 级6 输入LUT，而64 选1 MUX 就需要3
级，因此当 case 的条件信号位宽较宽，条件分支较多时，就很容易成为时序瓶颈。如果分支中用到的
上游信号已经经过组合逻辑电路，则问题会更严重。 
对此最简单有效的方法就是插拍。比如case 条件信号6 bits，64 个分支，代表3 级组合逻辑，上
游已经过1 级组合逻辑，因此总数为4 级。如果1GHz 只允许每个时钟周期内2 级，就需要在MUX 中间
插一级。

6.3 功耗优化 
6.3.1 Clock gating 
Clock gating 通过控制时钟信号的跳转，减少时钟网络功耗和对应的DFF 翻转功耗，达到优化功
耗的效果。 在电路中如果有某个子模块可以长时间不工作，譬如当某个模块处于用户不使能、 输入不跳
变、输出不被选中的情况时，便可将其时钟关断，以此节省时钟网络翻转所带来的动态功耗。 
Anlogic FPGA 的芯片按family 进行分类时， 包含有多种带使能的时钟缓冲器， 可以按需在Language 
Template 里查询调用。 
 
图 6-8 时钟缓冲器显示 
FPGA 芯片的时钟资源是有限的，该限制包括全局时钟和局部时钟，因此当调用时钟缓冲时会导致
时钟信号变多，而时钟信号过多可能会导致布局合法化困难，时钟信号布线困难。注意：TD 软件目前
不支持根据用户if (clock_enable) q <= d; 语句自动推导clock gate 逻辑。
