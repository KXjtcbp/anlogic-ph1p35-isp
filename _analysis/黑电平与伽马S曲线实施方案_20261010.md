## 0. 开工前必须先做的一件事：在当前增益下复测黑电平（P0）

**复测步骤（约 5 分钟）**

## 1. 黑电平校正（BLC）

### 1.1 摄影语言 ↔ 工程原理

| 摄影后期操作 | 对应的工程动作 | 本设计怎么做 |
|---|---|---|
| 拉黑场 / 设置"黑场吸管"（Blacks 左移、把黑点定在真正的 0） | 从每个像素减去一个固定的**光学黑基座（pedestal / OB）**，并把结果钳位到 0 防下溢 | 10bit 域每个字段减 `BLACK_LEVEL`，`>` 判断即钳位 |
| 黑场吸管不能点到"负值" | 减法必须带钳位，否则无符号下溢会回绕成大数（黑变白） | `(x > L) ? (x - L) : 0` |
| 8bit/10bit 量化时黑场会被"取整"抹掉细节 | 取高 8 位前加一个等于半 LSB 的**四舍五入偏置** | `+ ROUND_BITS`（默认 +2，等价 `(x-56+2)/4` 四舍五入） |

**一句话原理**：传感器输出的"黑"不是 0，而是一个正基座；这个基座被后面的除法/截断保留下来，就等于给整幅画面加了一层灰雾。黑电平校正 = 把这层灰雾的**地基**减掉。

**本设计不用 40bit 的 10→8 缩放了**：链路本来就是每个 RAW10 字段取高 8bit（`[9:2]`），所以"减基座 + 取高位"天然合并在同一级完成，不增加流水级、不改变链路延迟（仍是 1 拍）。

## 2. S 曲线（伽马 / 对比度）校正

### 2.1 为什么是 S 曲线，而不是 gamma<1

用户描述"像蒙了一层雾"= 黑场不黑 + 暗部对比不足（**不是**整体偏暗）。三种曲线的量化差别（`gen_gamma_lut.py` 实算，锚点 = 输入码值 → 输出码值）：

| 曲线 | 16 | 64 | 118 | 200 |
|---|---|---|---|---|
| 提亮暗部 gamma≈0.9 | 17 ↑ | 64 | 115 ↓ | 195 ↓ |
| 压暗 gamma≈1.1 | 15 ↓ | 71 ↑ | 121 ↑ | 206 ↑ |
| **S 曲线（本方案）** | **10 ↓** | **55 ↓** | **118 =** | **211 ↑** |

S 曲线把**中间调钉死在原地**（118→118），把暗部压下去（64→55）、把高光提起来（200→211）—— 这正是"压暗部、提亮高光、保留中间调"，量化上就是"黑场更黑、高光更亮、中间调不动"。

### 2.2 曲线公式与生成脚本

`E:\FPGA\_analysis\gen_gamma_lut.py`（已跑通，`--all` 一次生成全部变体）：

```python
def s_curve(x, pivot=118, a=1.25, b=1.25, toe=0):
    """S 曲线：pivot 以下按 A 次幂压暗，pivot 以上按 B 次幂提亮。
       A = B = 1.0 时退化为恒等（即 bypass）；A/B 就是拐点处的对比度增益。"""
    if x <= toe:            return 0
    if x <= pivot:          return round(pivot * (x / pivot) ** a)
    return round(pivot + (255 - pivot) * (1 - ((255 - x) / (255 - pivot)) ** b))
```

CLI：`python gen_gamma_lut.py --pivot 118 --a 1.25 --b 1.25 --toe 0 --prefix gamma_lut_p118_k125`

输出 4 种格式：`.mif`（TD IP 初始化）、`.coe`（备选）、`.vh`（Verilog `function` 查表，TB/仿真用）、`.hex`（`$readmemh` 给 TB 做全表比对）、`.txt`（人读对照表）。

**推荐表：`gamma_lut_p118_k125`（PIVOT=118，A=B=1.25）**

| 输入 | 0 | 16 | 32 | 64 | 96 | 118 | 128 | 160 | 200 | 224 | 255 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 输出 | 0 | 10 | 23 | 55 | 91 | 118 | 130 | 168 | 211 | 234 | 255 |

（以上 11 个值已从 `gamma_lut_p118_k125.hex` 逐条核对，不是估算值。）

- 单调不减、`y(0)=0`、`y(255)=255`、`y(118)=118`；
- **可用级数 235/256（丢 21 级）、最长平台 2 级** ⇒ 8bit 里几乎没有并阶；
- 暗部 64 码 −9、高光 200 码 +11 ⇒ 对比度可见提升。
- 备选强版 `p128_k145`（PIVOT=128、A=B=1.45）：16→6、64→47、200→217，对比更强但可用级数 222/256、最长平台 3 级。若上板觉得 1.25 不够，直接换这一份。
- `toe16` 变体（把 0..15 压成 0）**不推荐**：最长平台变 3 级，暗部并阶更明显，收益不抵代价。

```verilog
// 模块      : isp_gamma
// 功能      : 8bit/通道 的 S 曲线（对比度）校正。96bit/拍 = 4 像素 × {R,G,B}，
//             每拍 12 路并行查表；查表内容由 gen_gamma_lut.py 生成。

    parameter integer PIVOT   = 118,  // S 曲线拐点（中间调锚点，输出仍等于输入）
    parameter integer LATENCY = 1     // 总延迟（拍），必须与实现一致

    input  wire        I_rst_n,

//--------------------------------------------------------------------

genvar gb;
generate
    for (gb = 0; gb < 12; gb = gb + 1) begin : g_byte_in
        assign bytein[gb] = I_tdata[8*gb +: 8];
    end
endgenerate

//--------------------------------------------------------------------
// 2. 12 路并行查表
//--------------------------------------------------------------------
`ifdef GAMMA_USE_ERAM
    // ---- 上板用：256x8 ROM（TD IP 生成），ROM 自带 1 拍输出寄存器 ----
    wire [7:0] lut [0:11];

        for (gb = 0; gb < 12; gb = gb + 1) begin : g_rom
            gamma_lut_rom u_rom (
                .address (bytein[gb]),
                .clock   (I_clk      ),
                .q       (lut[gb]    )

`ifdef GAMMA_USE_ERAM
    reg  [7:0] bytein_d [0:11];   // ★ 旁路路径自己打 1 拍，才能与 ROM 输出对齐
`endif
integer i;
always @(posedge I_clk or negedge I_rst_n) begin
    if (!I_rst_n) begin
        for (i = 0; i < 12; i = i + 1) data_out[i] <= 8'd0;
`ifdef GAMMA_USE_ERAM
        for (i = 0; i < 12; i = i + 1) bytein_d[i] <= 8'd0;
`endif
    end else begin
        for (i = 0; i < 12; i = i + 1) begin
`ifdef GAMMA_USE_ERAM
            bytein_d[i] <= bytein[i];

`else
            data_out[i] <= I_gamma_bypass ? bytein[i] : lut[i];
`endif

    end

//--------------------------------------------------------------------

assign O_tlast  = l_sr[LATENCY];

//--------------------------------------------------------------------
```

```verilog
.I_tuser  (gam_O_tuser),
.I_tlast  (gam_O_tlast),
.I_tdata  (gam_O_tdata),
```

4. **不动**的几行（原厂语义，别顺手改）：
   - `isp_top.v:69 assign awb_O_tready = O_tready;` —— gamma 不参与反压，保持原样即可；
   - `isp_top.v:105 assign O_tlast = awb_O_tlast;` —— 原厂就是从 96bit 级取 tlast（与 `O_tuser` 取自 128bit 级不一致，是基线既有的事实）。插一级后 `O_tlast` 相对数据早 1 拍；本工程的显示侧用 tuser/帧起始定位，tlast 不参与判位。**若上板发现"每帧最后一行像素错位"，把 `:105` 改成 `algo_O_tlast`**（一行回退）。

### 2.5 ROM IP 配置（上板版）

| 项 | 值 | 说明 |
|---|---|---|
| IP 类型 | Block Memory Generator → **ROM** | TD 里叫 `ERAM`/`Block Memory`，见 `ip_source\*` 现有实例 |
| 位宽 | 8 | 一个字节通道一张表 |
| 深度 | 256 | 8bit 输入全表 |
| 读延迟 | **1 拍**（关闭/打开输出寄存器按向导默认，但必须与 `LATENCY=1` 一致） | 若向导只能给 2 拍：把 `LATENCY` 改成 2，并在旁路路径上把 `bytein_d` 打两拍 |
| 初始化 | `gamma_lut_p118_k125.mif` | `gen_gamma_lut.py` 已按 TD `.mif` 语法生成（含 `DEPTH=256; WIDTH=8;` 头） |
| 端口 | 地址 + 时钟 + 输出（只读） | 不需要写端口、不需要 we |
| 实例数 | **12**（每路一个地址端口） | ★ 12 路输入的地址各不相同，**不能合并成 1 个大 ROM**；若要省 ERAM，可用**双端口 ROM**（每块 2 路、6 块）—— 以综合后 `#RAMs` 实测为准 |

⚠️ **为什么必须 12 个独立查找**：一个 ROM 只有一个地址端口，而每拍要同时转换 4 像素 × 3 通道 = 12 个**互不相同**的字节。串行复用做不到（60 MHz 下每拍只有 1 个时钟，12 次查找需要 12 拍，而数据每拍来一次）。所以只能用"12 份并行表"或"6 份双端口表"。

### 2.6 bypass 逻辑

- **动态**：`I_gamma_bypass` 来自 SW2（拨上=1=直通）。旁路与查表在**同一级寄存器**汇合 ⇒ 两条路径延迟一致，切换时画面不跳行、不撕裂。
- **静态**：`PIVOT/--a 1.0 --b 1.0` 生成恒等表（`y=x`）⇒ 表本身就等于 bypass（可作为万一开关不够用时的兜底）。
- **寄存器版（可选）**：若后面要软件控制，把 `I_gamma_bypass` 换成 `r_gamma_en` 寄存器（挂在 24 MHz 配置域），本模块只占 1 个 FF。

## 3. 同步信号对齐（逐级延迟表）

| 信号 | 插入前延迟 | gamma 级 | 插入后总延迟 | 谁需要跟着打拍 |
|---|---|---|---|---|
| `tdata[95:0]` | awb 输出即用 | +1 拍 | +1 | 由 `isp_gamma` 内部 `data_out` 完成 |
| `tvalid` | awb 输出即用 | +1 拍 | +1 | `v_sr` 移位寄存器（**必须**，否则 my_algo 会对齐错） |
| `tuser`（帧起始） | awb 输出即用 | +1 拍 | +1 | `u_sr` |
| `tlast` | awb 输出即用 | +1 拍 | +1 | `l_sr` |
| `tready` | `assign awb_O_tready = O_tready;` | 不变 | 不变 | **不需要动**（gamma 无缓存、无反压） |

要点：
1. **三类流控信号与数据必须同拍数**：本模块把 tvalid/tuser/tlast 走同一组移位寄存器，天然同相。
2. **BLC 那一级不改变延迟**：黑电平校正在 `mipi_to_raw_converter` 内部与既有寄存器合并，仍是 1 拍（不会给 RAW 侧增加延迟）。
3. **不引入跨时钟域**：整个 gamma 级与 awb、my_algo 同在 `axi4s_video_aclk`（= `S_csi_rx_clk`，实测 **60 MHz**，`route_clock_utilization.txt` 的 `gclk_0 MIPI_RX_BYTE_CLK` 周期 16.668 ns）。
   > 附注：`isp_top.v:6` 的头注释写"约 100 MHz"是**过时错误**，实际是 60 MHz。本次改动可以顺手把注释更正（不影响逻辑）。
4. **时序**：ISP 域 60 MHz、每 4 像素一个有效拍（词率 13.8 Mword/s ⇒ 占空比约 23%），本模块最长组合路径 = 地址 → ROM/查表 → 1 个 8bit mux，深度 3~4 级 LUT，且被寄存器切开，不会成为关键路径（当前 `route.qor` Setup WNS 仅 +3 ps，瓶颈是布线/占用率而非逻辑深度）。

## 5. Testbench 模板

文件：`E:\FPGA\_analysis\tb_gamma\tb_isp_gamma.v`（仿真用**分布式 LUT 版**的 `isp_gamma.v`，把 `.vh` 的 function 直接粘进模块；表内容与上板 ERAM 版完全一致）。把 `gamma_lut_p118_k125.hex` 拷到仿真工作目录。

```verilog
`timescale 1ns/1ns
module tb_isp_gamma;
    localparam integer LATENCY = 1;
    reg         I_clk = 0, I_rst_n = 0;
    reg  [95:0] I_tdata = 0;
    reg         I_tvalid = 0, I_tuser = 0, I_tlast = 0, I_gamma_bypass = 0;
    wire        O_tvalid, O_tuser, O_tlast;
    wire [95:0] O_tdata;

    reg  [7:0]  gold [0:255];       // 黄金表（gen_gamma_lut.py 生成的 .hex）
    reg  [95:0] exp, d;
    integer     x, b, errors = 0;

    always #5 I_clk = ~I_clk;       // 仿真时钟，频率与逻辑无关

    isp_gamma #(.PIVOT(118), .LATENCY(LATENCY)) dut (
        .I_clk(I_clk), .I_rst_n(I_rst_n),
        .I_tvalid(I_tvalid), .I_tuser(I_tuser), .I_tlast(I_tlast),
        .I_tdata(I_tdata), .I_gamma_bypass(I_gamma_bypass),
        .O_tvalid(O_tvalid), .O_tuser(O_tuser), .O_tlast(O_tlast), .O_tdata(O_tdata));

    // 送出 1 拍数据（在时钟低电平驱动，避免竞争）
    task send (input [95:0] td, input v, input u, input l, input bp);
        begin
            @(negedge I_clk);
            I_tdata = td; I_tvalid = v; I_tuser = u; I_tlast = l; I_gamma_bypass = bp;
        end
    endtask

    // LATENCY 拍后比较数据与三个流控信号，然后清空输入
    task expect (input [95:0] td, input v, input u, input l, input [255:0] tag);
        begin
            repeat (LATENCY) @(negedge I_clk);
            if (O_tvalid !== v || O_tuser !== u || O_tlast !== l) begin
                errors = errors + 1;
                $display("[%0s] FAIL 流控: valid=%b user=%b last=%b 期望 %b/%b/%b",
                         tag, O_tvalid, O_tuser, O_tlast, v, u, l);
            end
            if (O_tdata !== td) begin
                errors = errors + 1;
                $display("[%0s] FAIL 数据: 得 %024h 期望 %024h", tag, O_tdata, td);
                for (b = 0; b < 12; b = b + 1)
                    if (O_tdata[8*b +: 8] !== td[8*b +: 8])
                        $display("        字节%0d: 得 %02h 期望 %02h",
                                 b, O_tdata[8*b +: 8], td[8*b +: 8]);
            end
            @(negedge I_clk);
            I_tvalid = 0; I_tuser = 0; I_tlast = 0;
        end
    endtask

    initial begin
        $readmemh("gamma_lut_p118_k125.hex", gold);
        repeat (4) @(negedge I_clk);
        I_rst_n = 1'b1;
        repeat (2) @(negedge I_clk);

        //======== 用例 1：12 路同时给不同的值（含 0/16/64/118/128/200/255）========
        d = 96'd0;
        d[ 7: 0]=8'd0;   d[15: 8]=8'd16;  d[23:16]=8'd64;  d[31:24]=8'd118;
        d[39:32]=8'd128; d[47:40]=8'd200; d[55:48]=8'd255; d[63:56]=8'd0;
        d[71:64]=8'd16;  d[79:72]=8'd64;  d[87:80]=8'd118; d[95:88]=8'd128;
        exp = 96'd0;
        for (x = 0; x < 12; x = x + 1) exp[8*x +: 8] = gold[d[8*x +: 8]];
        send(d, 1'b1, 1'b1, 1'b1, 1'b0);
        expect(exp, 1'b1, 1'b1, 1'b1, "用例1-查表");
        $display("用例1 期望 12 个字节 = %02h %02h %02h %02h %02h %02h %02h %02h %02h %02h %02h %02h",
                 exp[7:0],exp[15:8],exp[23:16],exp[31:24],exp[39:32],exp[47:40],
                 exp[55:48],exp[63:56],exp[71:64],exp[79:72],exp[87:80],exp[95:88]);

        //======== 用例 2：bypass=1，输出必须等于输入（且流控仍然对齐）========
        send(d, 1'b1, 1'b0, 1'b1, 1'b1);
        expect(d, 1'b1, 1'b0, 1'b1, "用例2-bypass");

        //======== 用例 3：全表扫描 x=0..255，12 路同值，逐点比对黄金表 ========
        for (x = 0; x < 256; x = x + 1) begin
            d = 96'd0;
            for (b = 0; b < 12; b = b + 1) d[8*b +: 8] = x[7:0];
            exp = 96'd0;
            for (b = 0; b < 12; b = b + 1) exp[8*b +: 8] = gold[x];
            send(d, 1'b1, 1'b0, 1'b0, 1'b0);
            expect(exp, 1'b1, 1'b0, 1'b0, "用例3-全表");
        end

        //======== 用例 4：复位后再来一拍，确认复位后通道正常 ========
        I_rst_n = 1'b0; repeat (2) @(negedge I_clk); I_rst_n = 1'b1;
        repeat (2) @(negedge I_clk);
        d = 96'd0; d[7:0] = 8'd200;
        exp = 96'd0; exp[7:0] = gold[200];
        send(d, 1'b1, 1'b1, 1'b0, 1'b0);
        expect(exp, 1'b1, 1'b1, 1'b0, "用例4-复位后");

        if (errors == 0) $display("=========== 全部通过 (errors = 0) ===========");
        else             $display("=========== 失败 %0d 处 ===========", errors);
        $stop;
    end

    initial begin #2_000_000; $display("FAIL 仿真超时"); $stop; end   // 看门狗
endmodule
```
