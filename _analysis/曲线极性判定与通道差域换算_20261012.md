- **作者**：成员 B（AI 协助）
- **复核对象**：`captures/2026-10-12_照亮后三图/`、`captures/2026-10-12_AWB诊断基准面/`
- **用到的脚本**：`_analysis/scripts/_gamma_polarity_check.py`（本次新增）、`_analysis/scripts/stat_imgs.py`（未改）
- **一句话结论**：K=45 的 S 曲线表确实在通路里、且就是 `isp_gamma.v` 里那张 `mem_b00`；但
  ① **「SW2 上 = 曲线直通」这个文档口径与实测相反**（实测 SW2 上是曲线**生效**）；
  ② **所有「色差 X 码」的说法都必须标注在曲线前域还是曲线后域**——`20_uniform_surface_CNT106211.png`
  那条 −3.16 码在曲线前域只有 **−2.09** 码。
- **本文件不改任何 RTL、不引入任何新 IP、不需要上板。**

## 1. 方法与复现

```powershell
# 在仓库根目录，python 用任意带 numpy/Pillow 的解释器
python _analysis/scripts/_gamma_polarity_check.py `
  "captures/2026-10-12_照亮后三图/10_SW1up_SW2dn_SW3up_SW4up_curveOFF_31.5x.png" `
  "captures/2026-10-12_照亮后三图/11_SW1up_SW2up_SW3up_SW4up_curveON_31.5x.png" `
  "captures/2026-10-12_AWB诊断基准面/20_uniform_surface_CNT106211.png"
```

脚本做三件事：

1. 从 `isp_gamma.v` 解析 `mem_b00` 的 256 项（正则只认数字下标的赋值，排除
   `mem_b10[k] = mem_b00[k];` 这类复制行，解析不完整会直接报错退出）；
2. 对每张图算三通道均值、R−G、B−G、R/G、B/G，并做**双向点对点检验**：
   `mean(LUT(A))` 与 `mean(B)` 比、`mean|LUT(A)-B|`、`corr(A,B)`，以及经验映射
   `e(v) = mean(B | A == v)` 对 LUT 与恒等各比一次残差；
3. 用反表 `inv = searchsorted(lut, v)` 把通道差在**曲线前 / 曲线后**两个域之间换算。

遮罩与统计口径与 `stat_imgs.py` 完全一致：`osd_mask` 按 `s = w/1280.0` 缩放，
遮掉 `(0,0,180,180)`、`(360,110,600,150)`、`(165,165,270,195)` 三块；`Y = (77R+150G+29B)>>8`。
图都是 1920×1080（s = 1.5）。

## 2. 解析出的表（`proj/baseline/lab3/user_source/hdl_source/isp/isp_gamma.v` 的 `mem_b00`）

```
x    :   0   1   2   8  16  32  43  58  64  69  96 128 160 192 224 255
y    :   0   0   0   3  22  49  63  79  85  89 112 134 154 174 199 255
```

- 斜率：最小 0 @ x=0（黑位下压），最大 10 @ x=254（高光回满），
  **暗部 x=8..64 平均斜率 1.464**（这正是把前域通道差放大的那一级）。
- 12 张表（`mem_b00..mem_b11`）内容严格相同：`:206 mem_b10[k] = mem_b00[k]; mem_b11[k] = mem_b00[k];`
  ⇒ **该级不可能产生通道间差异**，任何 R/B 相对 G 的缺口都不是它造的。

## 3. 结论一：曲线极性（哪一档才是「曲线生效」）

| 假设 | `mean(LUT(曲线前))` | `mean(曲线后实测)` | 差 |
|---|---|---|---|
| **10 是曲线前 → 11 是曲线后** | 68.441 | 69.021 | **+0.580 码** ✅ |
| 11 是曲线前 → 10 是曲线后 | 81.484 | 57.740 | −23.744 码 ❌ |

- 逐像素残差 `mean\|LUT(10)-11\| = 20.681`、`mean\|10-11\| = 24.146`、`corr(10,11) = 0.755`
  —— 两张图**不逐像素对齐、也未必同曝光**，所以逐像素残差不可用；但**均值/分布检验不受对齐影响**，
  +0.58 码的吻合就是「曲线就是这张表」的证据强度。
- ⇒ **`10_SW1up_SW2dn_..._curveOFF`（SW2 下）= 表不生效；`11_SW1up_SW2up_..._curveON`（SW2 上）= 表生效。**
  与文件名的 curveON/curveOFF 一致，与 RTL 注释（见 §5）相反。

## 4. 结论二：通道差必须标域（曲线前 = AWB 输出）

| 图 | 实测 R−G / B−G | 当作曲线后 → **拉回曲线前** | 当作曲线前 → 推到曲线后 |
|---|---|---|---|
| 10（曲线关，天然前域） | −3.165 / −3.007 | −3.276 / −1.761 | −3.097 / −4.258 |
| 11（曲线开） | −2.547 / −3.086 | **−3.022 / −2.638** | −2.234 / −3.784 |
| 20 均匀面（状态未记录） | −3.157 / −3.015 | **−2.091 / −1.959** | −3.670 / −3.643 |

- ★ 10 的**实测**（曲线关 ⇒ 天然就是 AWB 输出域）给出 −3.165 / −3.007；11 **换算回前域**给出
  −3.022 / −2.638。两条独立路径在同一个域里吻合到 **0.14 / 0.37 码** ⇒ 换算可信，
  **AWB 输出域（曲线前）的真实缺口 ≈ −3.0 码**。
- ★★ 但**所有文档引用的那张 `20_uniform_surface_CNT106211.png` 曲线状态没有记录**：
  若曲线关 ⇒ 前域缺口 −3.16；若曲线开 ⇒ 只有 **−2.09**（差三分之一）。
  引用该图的数字时必须写明「曲线状态未记录」，并优先补拍（见 §7）。
- 结论：**今后任何「色差 X 码」的表述都要带域标注**，否则同一现象在暗部会被曲线放大 1.5 倍左右。

## 5. 结论三：极性矛盾的定位——在命名，不在代码

追线结果（`I_gamma_bypass = 1` ⇒ 整级直通）：

```
isp_gamma.v:214        reg [95:0] d1;      // 与 rom_q 同拍的「原数据」，供旁路用
isp_gamma.v:233        d1 <= I_tdata;
isp_gamma.v:237        b1 <= I_gamma_bypass;
isp_gamma.v:261        q2 <= b1 ? d1 : rom_q;     // 旁路：整级直通（延迟仍是 2 拍）

isp_top.v:43           input  I_gamma_bypass,
isp_top.v:250          .I_gamma_bypass ( I_gamma_bypass   ),

design_top_wrapper.v:867   S_sw2_sync0 <= I_switch[1];
design_top_wrapper.v:868   S_sw2_sync1 <= S_sw2_sync0;
design_top_wrapper.v:877   wire S_gamma_bypass = S_sw2_sync1;   // 1 = S 曲线直通
design_top_wrapper.v:882   assign O_led = {S_sw4_sync1, S_sw3_sync1, S_sw2_sync1, S_sw1_sync1};
design_top_wrapper.v:916   .I_gamma_bypass (S_gamma_bypass),
```

- **【2026-10-12 晚已定案：这条不是矛盾，是命名口径】**
  `proj/baseline/lab3/user_source/constraints_source/pin.adc:21-24` 原文写着
  「board manual: up=1, down=0」+「★实测极性（与手册相反）: 拨下 = 逻辑 1，拨上 = 逻辑 0★（RTL 里用 ~sync 还原语义）」，
  以及 `SW2=B4 : S-curve (gamma) bypass (1=through/legacy, 0=enable S-curve)`。
  ⇒ 逻辑 1 = 直通 = **拨下** = SW2 下 = 直通；**SW2 上 = 曲线生效** —— 与本文实测完全一致。
- A 已代验 `O_led[2]`：SW2 拨上时读到 0。`README.md:85` 原本写的就是「上 = 曲线启用」⇒
  **`docs/` 里没有任何说法需要翻面**，`docs/给成员C的prompt.md` 也不用改。
- 本节最初那条结论（「反转发生在逻辑位 ↔ 物理上/下的命名上，可能要整体翻面」）**作废**：当时只追了 RTL 接线，
  没查约束文件里早就写好的实测极性注释。教训：**判开关极性要同时看 RTL 与 `pin.adc` 注释**。

## 7. 对本轮 AWB 调查的影响 / 待办

三条硬事实目前两两冲突，必须靠**同一场景下的 MODE 0 / MODE 1 对照**一次定死：

- **AWB 定理**：增益 = 本帧自身的 ΣG/ΣR，而乘的又是本帧像素 ⇒ 均匀面输出均值恒等于 G，
  唯一偏差是 `[23:16]` 截断（平均 −0.5、最多 −1 码）。**给不出 −3 码。**
- **MODE 1 对照（历史数据）**：10-11 那次在 Y=64 实测 MODE 1（构造性 R=G=B）得
  `R/G = B/G = 1.000` ⇒ 采集链在 Y≈64 无通道差。但**该亮度不是出问题的 Y≈43**，必须重测。
- **实测**：均匀面在 AWB 输出域（曲线前）缺口 ≈ −3.0 码。
