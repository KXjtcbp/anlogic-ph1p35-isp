# 平台卡 · 模板

> **平台卡是什么**：针对一类硬件平台（FPGA / MCU / SoC+ARM / …）的"能力边界 + 专属坑 + 最小验证路径"。
> 主文件（`01`~`09`）只写平台无关的方法；**所有和具体硬件绑定的内容都收在平台卡里**。
>
> **怎么用**：项目启动时填一张平台卡（10 分钟），之后调试时对着"坑"那一节逐条排除。

---

## 复制这张模板新建一张卡

```markdown

## 0. 一句话定位
这块平台最强的是 ______，最不适合的是 ______。

|---|---|
| ① 感知 | |
| ② 执行 | |
| ③ 算力 | |
| ④ 通信 | |
| ⑤ 呈现 | |

## 2. 资源口径（有"标称值 ≠ 工具报告值"这类陷阱的必须写清）

| 项 | 标称 | 工具实测/可用 | 说明 |
|---|---|---|---|

## 3. 工具链与最小验证路径
- 编译/综合命令：______
- **什么算"构建成功"**（四判据）：______

|---|---|---|

| 典型目标 | 可测的判据 |
|---|---|

## 7. 迁移提示（从别的平台过来最容易犯的错）
```

## 命名与存放

```
docs/competition-playbook/platforms/
├── _平台卡模板.md     ← 本文件
├── fpga.md
├── mcu.md
├── soc-arm.md
└── <你的平台>.md
```

> **规则**：平台卡里**只放这个平台独有**的东西。凡是"任何平台都适用"的（比如"改之前先写判据"），一律写在 `03`，平台卡里只留一句指向。
