# 工科竞赛与开发板探索 · 通用方法论 Playbook

> 一套与**具体赛题、具体平台**解耦的工程打法。
>
> **来源**：2026 年全国大学生嵌入式芯片与系统设计竞赛 FPGA 创新设计赛道（选题二，安路 PH1P35）的完整参赛实践 + 同类竞赛（集创赛 / 电赛 / 智能车）公开的获奖经验。
> **适用范围**：工科类竞赛（FPGA / 嵌入式 / 单片机 / ARM / 电赛 / 集创赛 / 智能车）、课程设计，以及"我手头有一块开发板，能拿它做什么"这类从零探索。

---

## 0. 这份文档是什么

不是教程，是**一份在项目每个阶段都能来查的作战手册**。它回答五个问题：

1. **现在这个阶段，我该把时间花在哪？** → `01`
2. **题目看不懂 / 有板子但没想法，怎么往下推？** → `02`（从题出发）或 `07`（从板出发）
3. **东西做出来了，怎么判断它是真的能用？** → `03`、`04`
4. **怎么把它讲清楚、演出来？** → `08`
5. **AI 能帮我多少、红线在哪？** → `09`

## 1. 三层结构（先理解这个，再决定读哪份）

```
第一层 · 方法层（与平台无关，换任何比赛/平台都不改）
  README.md  01  02  03  04  05  06  07  08  09
        ↑
第二层 · 参数层（换比赛/换板子就整份重填）
  _本项目配置.md
        ↑
第三层 · 平台层（换板子就换一张卡）
  platforms/fpga.md  platforms/mcu.md  platforms/soc-arm.md  platforms/_平台卡模板.md
```

- **方法层**回答"怎么想、怎么做、怎么验、怎么交"，写的是可迁移的动作。
- **参数层**只装这一场比赛的具体值：芯片型号、工具链路径、评分表、提交项、团队人数。
- **平台层**只装这一块板子独有的东西：资源口径、工具链、构建成功判据、专属坑。

> **为什么这样分**：换一场比赛，`_本项目配置.md` 整份重填，方法层一行不动；换一块板子，只换一张平台卡，方法层一行不动。
> 混在一起的后果是：每次都要在一堆 FPGA 细节里翻"流程该怎么排"，翻不到。

## 3. 标注约定（全文通用）

文档里每条经验都带来源标记，**读的时候请注意区分可信度**：

- **`[实践]`** —— 本项目亲身验证过，有具体数字或可复现步骤。
- **`[外部]`** —— 来自同类竞赛公开作品 / 复盘、开源项目、教材、厂商文档，**未在自己手上验证**，采纳前请自行判断。
- **`[推断]`** —— 基于现有证据的合理推测，不是实测结论。看到这个标记，决策前要自己补验证。

> 混用这三种来源是写复盘最常见的错误：把"我觉得"写成"实践证明"，下一次就会照着它做错事。

**`platforms/` 下各卡的标注分布**：

| 平台卡 | 标注 | 说明 |
|---|---|---|
| `platforms/fpga.md` | 以 `[实践]` 为主 | 本项目亲验（安路 PH1P35 + TangDynasty） |
| `platforms/mcu.md` | 几乎全是 `[外部]` | 通用嵌入式实践，非本项目亲验 |
| `platforms/soc-arm.md` | 几乎全是 `[外部]` | 通用嵌入式 Linux 实践，非本项目亲验 |

## 4. 在新对话中如何引用这份文档

**推荐做法**：每次开新对话，把下面这段原样贴进第一条消息。

```
先读这几份文件，再回答我：
1. <playbook 目录>\README.md
2. <playbook 目录>\_本项目配置.md
3. 按 README 第 2 节的触发条件表，读当前阶段对应的那一份
4. 如果涉及具体硬件，再读 platforms\ 下对应的平台卡

读完后：
- 用 3 句话概括当前阶段我该做什么、不该做什么
- 指出配置里哪些字段还是空的（_本项目配置.md 里的「待填」/「⬜」）
- 然后开始干活，不要只是复述文档
```

**为什么这样引用**：
- 只读 README 会给泛泛而谈的建议——因为方法层里没有你的具体参数
- 只读配置会照搬——因为参数层里没有判断
- **读"方法 + 参数 + 当前阶段那一份"才能给出具体建议**
- 要求它先"概括 + 指出缺口"，**是为了验证它真的读进去了**（如果它复述不出你的芯片型号，就说明没读配置）

**如果换了比赛**：复制整个 `competition-playbook\` 文件夹到新工作区，只改 `_本项目配置.md`（10 分钟）。
**如果换了平台**：再加一步，把 `platforms/` 下对应的平台卡填一遍（30 分钟），或者按 `platforms/_平台卡模板.md` 新建一张。

## 6. 一句话总纲

> **选题和方案阶段改主意是免费的，实现阶段改主意是很贵的，提交前改主意是不可能的。**
> 所以时间要倒过来投：越是前面，越要多花。
>
> 我们这次的失分，80% 在选题那一周就决定了。
