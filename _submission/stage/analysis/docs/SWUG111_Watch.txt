2.4.3.4 触发条件设置区 
触发条件设置区，用于设置采样触发的条件、位置信息。如下图所示。 
 
图 2-62 触发条件设置区  
触发条件设置区左边窗口是当前ChipWatcher 全局触发设置，相关参数如下： 
 
Number of windows：波形触发窗口个数设置，默认值为1，可设置范围为1~ Sample Depth；当设
置多个触发窗口时，会对设置的触发条件进行多次触发采样，并将多次采样到的数据在一个界面内
分多个窗口进行显示。 
 
Window of depth：窗口采样深度，默认值为1 个窗口时的最大采样深度，该深度值为ChipWatcher
例化时设置的采样深度，可设置范围为1~（Sample Depth/ Number of windows 的整数）；当Number 
of windows 设置的窗口数更改时，窗口采样深度值也会更改为此窗口数时计算到的最大采样深度。 
 
Trigger Position in window：触发位置，用户可直接输入数值，该值可更改的范围由ChipWatcher
例化时设置的采样深度即Sample Depth 大小有关，可设置0~Sample Depth-1。 
 
Trigger Condition：多个触发条件逻辑运算；Basic AND，逻辑与运算即需满足所有触发条件才能
进行触发；Basic OR，逻辑或运算即只需满足其中一个触发条件即可进行触发。

2.4.3.6 ChipWatcher 上电触发功能

2.5 ChipWatcher 离线调试 
ChipWatcher 离线调试指脱离工程进行上板调试查看信号波形。如果需要进行离线调试的场景，用
户需要导出工程配套的调试文件。 
离线调试的流程步骤如下。 
 第一步，导出调试文件。 
Flow 编译完成Generate Bitstream 生成bit 文件后，打开ChipWatcher 设置界面，点击
ChipWatcher 界面上方Export 按钮，会弹出导出文件保存路径选择窗口，如下图所示。用户可自定义
保存路径，如不选择文件夹则默认保存在工程路径下。导出文件包括compiled.bit，compiled.cwc，
compiled.data 文件，其中.bit 和.cwc 为必要文件，.data 是波形配置文件，为非必要文件，需在Watch
界面对相关波进行配置保存后才能导出。如有上电触发功能时或者有保存已设置的波形触发条件时，则
需要同时加上.data 文件。当工程中有多个Run 时，则导出文件为当前Active Run 下的文件。
