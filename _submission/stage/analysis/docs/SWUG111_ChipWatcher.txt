1 概述 
本文档主要介绍了TangDynasty®（以下简称TD 软件）软件中调试工具ChipWatcher 的界面操作和
使用，可协助用户在进行逻辑功能上板调试时，快速熟悉和使用这些调试工具。 
2 ChipWatcher 
2.1 ChipWatcher 简介 
ChipWatcher 是TD 内部逻辑在线分析工具。通过ChipWatcher，用户无需借助外部设备即可在线监
测设计内部信号的变化情况。在 ChipWatcher 中，用户可同时添加多个观察信号；支持多个时钟域，
每个时钟域分为不同界面独立观察信号、独立设置采样深度、触发条件及触发位置等。ChipWatcher 支
持多种插入方式，如源码插入ChipWatcher IP、源码添加Mark Debug 命令、Read Design 后添加Mark 
Debug 标记、Optimize Gate 后插入ChipWatcher，既可监测源代码信号也可监测网表信号。

ChipWatcher 分为源码插入ChipWatcher IP 方式、源码添加Mark Debug 命令方式、Read Design 
后添加Mark Debug 标记方式、Optimize Gate 后插入ChipWatcher 方式。

2.2.2 Mark Debug 方式 
Mark Debug 方式是将想要监测的信号通过添加Mark Debug 标志后，软件即会自动识别该信号的驱
动时钟源作为触发时钟并根据时钟分配到相应ChipWatcher instance 的探针即Probe 上，即可实现对
该信号进行监测。该方式可通过两种途径对信号进行Mark Debug：一种是通过在工程源文件中添加Mark 
Debug 命令进行标记；另一种是在Flow 编译完Read Design 后通过ChipWatcher 的Mark Debug 界面
进行标记。

2.2.2.2 Verilog 源文件命令格式 
在Verilog 源文件中，如对信号test 进行Mark Debug 标记有如下几种方式，选择其中任意命令都
可以，命令不区分大小写。只能在信号定义处进行Mark Debug 标记。 
（*MARK_DEBUG = “TRUE”*）reg test; 
reg test;//synthesis MARK_DEBUG = TRUE 
reg test;// synthesis MARK_DEBUG = 1 
reg test;// synthesis MARK_DEBUG  
reg test;/*synthesis MARK_DEBUG = TRUE*/ 
reg test;/*synthesis MARK_DEBUG = 1*/ 
reg test;/*synthesis MARK_DEBUG*/ 
Tips：推荐使用（*MARK_DEBUG = “TRUE”*）reg test;方式，其他注释方式请按照上面介绍放于
所标注信号后面，才能精准定位到想要标记的信号。 
2.2.2.3 VHDL 源文件命令格式 
在VHDL 源文件中，如对信号test 进行Mark Debug 标记方式如下，命令不区分大小写。只能在信
号定义处进行Mark Debug 标记。 
signal test:std_logic; 
attribute MARK_DEBUG : BOOLEAN;  
attribute MARK_DEBUG of test_cnt : signal is TRUE; 
注意，和IO Logic Model 相接的输入/输出Port，不能被Mark Debug，会导致IO Logic 无法被
Mapping，在Opt Gate 阶段报错。 
2.2.2.4 源码添加Mark Debug Flow 编译 
当源码添加完Mark Debug 命令标记，保存文件后，即可运行Flow，如果中途不需要添加信号进监

认配置，即：采样深度默认为1024，默认勾选Data Enable 和Trigger Enable，默认不勾选Power On 
Trigger，Input Pipe Stage 和Output Pipe Stage 默认值为0。如需更改配置信息，可在Opt Gate

2.3.1 Clear Up ChipWatcher 
Clear Up ChipWatcher，即清除ChipWatcher，会清除Read Design 后Mark Debug 界面所有标记
和设置以及Optimize Gate 后添加的所有调试信号以及配置信息，但不会清除源码中例化的
ChipWatcher IP 和添加的Mark Debug 标记，即源码插入的ChipWatcher Instance 仍然有效。 
当右键点选Clear Up ChipWatcher 时，会弹出如下图所示的Warning 弹窗，提示是否确认删除，
如确认则点击Yes，如取消该操作则点击No。
