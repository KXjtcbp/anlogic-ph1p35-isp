6. 反推参数建议（给 Agent：如何让 FPGA 从 before 逼近 after）
==============================================================================
  以下每一条都是「测量值 -> 公式 -> 目标常数/寄存器」的推导；
  本工程链路假设：RAW10 -(减 S_blk_level, >>2)-> RAW8 -> demosaic -> AWB -> my_algo -> HDMI。
【1. 黑电平（Black Level）】
  before 黑场(P1)=51.0，after 黑场(P1)=68.0，差 -17.0 码值(8bit)
  before 纯黑像素占比=0.00%，after=0.00%
  要让 8bit 黑场+17.0 码值，10bit 域 S_blk_level 需 -68.0 -> -12
  -> ★ S_blk_level 会变成 -12（< 0，物理上不可实现）⇒ 这部分黑场差【不可能】靠黑电平实现。
     它更像是 after 做了「暗部抬升 / 加曲线」：请改走第 2 节的 gamma 或第 6 节的线性映射 out = a*in + b（b 项即黑场平移量），而不是动黑电平。

【2. Gamma / 中间调（Tone Curve）】
  按 11 个分位点(x=before 灰度, y=after 灰度)在 log-log 空间拟合 y = x^gamma：
     等效 gamma = 0.802
  -> 需要 提亮中间调：按 out = 255*(in/255)^0.802 实现（gamma<1 提亮）
       LUT[ 32] =  48
       LUT[ 64] =  84
       LUT[ 96] = 116
       LUT[128] = 147
       LUT[160] = 175
       LUT[192] = 203
       LUT[224] = 230
  中间调均值：before=88.6 -> after=109.5（目标中性灰约 118）
  -> before 中间调偏离目标，若要以「标准曝光」为准，亮度需 x1.332（或反向 x0.751）

【3. 该加曝光还是该加增益（AE/AGC 方向判别）】
  有效信号比 (after 的 P99-P1)/(before 的 P99-P1) = 0.981
  黑场变化 = -17.0 码值；白场变化 = 14.0 码值
  -> 信号幅度基本不变而黑场整体平移 => 这属于【偏置/暗部曲线】类改动，既不是曝光也不是增益。实现方式二选一：
     (a) 改 S_blk_level —— 仅当第 1 节算出的新值落在 2..200 的有效区间内；
     (b) 在 my_algo 的像素级流程里加线性映射 out = a*in + b（见第 6 节），b 项就是这里的黑场平移量（暗部抬升通常只能这样实现）。

【4. 增益寄存器换算（SC500CS）】
  不需要提高增益（信号比 0.981，未见变亮需求）。

【5. 白平衡（AWB）】
