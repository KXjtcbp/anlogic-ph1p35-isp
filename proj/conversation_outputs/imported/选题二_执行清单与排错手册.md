## 3. 上板排错速查手册

> **总原则**：先用"分步点亮 + 二分定位"把故障范围缩小到一半，再去查具体原因。**不要在全功能工程上猜 bug。**

### 3.1 显示类故障

| 现象 | 可能原因（按概率排序） | 怎么验证 | 怎么解决 |
|---|---|---|---|
| 显示器完全无信号 / 黑屏 | ① HDMI 时钟未输出 ② 引脚约束错 ③ TMDS 编码器错 ④ 显示器不支持该分辨率 | ① 示波器测 HDMI 时钟脚 ② 核对原理图逐脚对 ③ 用 `test_pattern` 出纯色 | ① 检查 PLL 与时钟分配 ② 改约束 ③ 先出纯色再出彩条 ④ 换 720p60 |
| 有信号但满屏雪花 | ① TMDS 编码表错 ② 串化时钟相位错 ③ 差分对约束错 ④ DC 平衡未做 | 用 `test_pattern` 出纯红/纯绿/纯蓝，看颜色是否纯净 | ① 复核编码表 ② 调整 OSERDES 时钟相位 ③ 检查差分对引脚 ④ 补 DC 平衡逻辑 |
| 画面偏色（整体红/蓝/绿） | ① 三通道映射错 ② Bayer 相位错 ③ RGB↔YCbCr 量化范围错 | 用纯色测试图案逐一验证通道 | ① 交换通道 ② 换 Bayer 相位（RGGB/BGGR/GRBG/GBRG）③ 统一用 full range 或按规范转换 |
| 画面发灰、发白、对比度低 | 量化范围错（limited 16–235 vs full 0–255） | 显示黑白渐变测试图，看最黑/最白是否到位 | 统一量化范围；或加 Gamma 校正 |
| 画面撕裂 / 上下半屏不同步 | ① 帧缓存乒乓切换不在消隐期 ② 采集与显示时钟未解耦 | 静态画面下看有无水平分界线；慢慢转摄像头 | ① 切换逻辑改到 `vsync` 后消隐期 ② 加帧缓存/异步 FIFO |
| 图像水平方向错位/偏移 | ① `x` 坐标与 `de` 不对齐 ② HFP/HBP 参数错 | 出棋盘格测试图，数格子是否对齐 | 修正时序计数器与 de 的产生逻辑 |
| 图像垂直方向滚动 | 帧同步丢失，VSync 极性错 | 检查 VSync 极性与帧计数器 | 修正极性；加帧同步状态机 |
| 图像有竖条纹/黑边 | ① 行缓存边界处理错 ② 行缓存深度算错 ③ 行首/行尾像素丢失 | 用窄图（如 32×32）和单像素点图案测试 | 修边界处理；重算行缓存深度 |
| 边缘有一圈黑边 | 3×3 窗口在图像边界时未做边界扩展 | 用全白图测试，看四条边是否为黑 | 边界复制（replicate）或补零并说明 |
| 画面整体偏移一两个像素 | 流水线延迟未做时序对齐（data 与 de/hs/vs 未同步打拍） | 出十字线测试图 | 所有控制信号与数据同步延迟相同拍数 |
| 显示正常但过几秒闪一下 | ① 时钟不稳 ② 电源纹波 ③ DDR 读写冲突 | 换电源、示波器看电源 | 换独立电源；加去耦；检查 DDR 仲裁 |
| OSD 位置不对/闪烁 | ① OSD 与视频不同步 ② 字库位序错 ③ Alpha 混合溢出 | 把 OSD 位置设为变量逐步移动 | ① OSD 用像素时钟同步 ② 换位序 ③ 检查位宽 |

### 3.2 采集类故障

| 现象 | 可能原因 | 怎么验证 | 怎么解决 |
|---|---|---|---|
| 完全无数据（帧计数不增） | ① 排线未插好/插反 ② 摄像头未上电 ③ MCLK 未输出 ④ I2C 配置未成功 ⑤ 复位时序不对 | ① 重插排线 ② 万用表测供电 ③ 示波器测 MCLK ④ 读回 ChipID ⑤ 读摄像头寄存器回读值 | 逐项排查；先确认 ChipID 能读回 |
| I2C 读不到 ChipID | ① 从机地址错（7 位 vs 8 位）② 上拉电阻/电平 ③ 时序不满足 ④ 摄像头未复位 | 逻辑分析仪抓 I2C 波形 | ① 地址左移/右移试 ② 检查上拉 ③ 降 I2C 频率到 100 kHz ④ 加上电延时 |
| 有数据但画面全黑/全白 | ① Bayer 相位/格式错 ② 位宽对齐错 ③ 数据位序反 | 用 OSD 显示某几个像素的原始值 | 对照手册确认输出格式与位序 |
| 画面噪声大/有彩色噪点 | ① D-PHY 速率不匹配 ② 走线/端接 ③ 数据打包解析错（RAW10） | 降低分辨率/帧率试 | 检查 D-PHY 配置；核对 RAW10 解包逻辑 |
| 画面偶尔跳变/丢帧 | ① 摄像头输出不稳定 ② FIFO 溢出 ③ 帧同步错 | 看 `fifo_overflow_cnt` 与 `crc_err_cnt` | 加深 FIFO；加帧同步状态机；检查供电 |
| 画面卡住不动 | ① 状态机死锁 ② DDR 挂死 ③ 复位未正确释放 | 看 `state` 寄存器、`pll_locked` | 加非法状态恢复；检查 DDR 控制器复位 |

### 3.3 稳定性类故障（最难查，对应 F4 与评分）

| 现象 | 最可能原因 | 定位方法 | 解决 |
|---|---|---|---|
| **偶发花屏（几秒一次）** | **CDC 问题**（多 bit 直接跨时钟 / 同步器不足） | ① 列出所有跨时钟边界 ② 逐个确认用了异步 FIFO/握手 ③ 长时间跑机配合错误计数器定位相关性 | 全部改为异步 FIFO 或握手；复位加同步释放 |
| 上电有时能显示有时不能 | ① PLL 未 lock 就释放了逻辑复位 ② 上电时序 ③ 电源上升沿慢 | 用 `pll_locked` 作为复位释放条件，观察是否相关 | 复位逻辑改为"外部复位 OR 未锁定" |
| 运行几分钟后失效 | ① 温度过高 ② 电源不足/纹波 ③ DDR 时序余量不足 | 用手摸芯片温度；示波器看电源；记录失效时间 | 加散热；换电源；降 DDR 频率或加余量 |
| 光照变化后算法失效 | 固定阈值 + 无自动曝光 | 遮挡镜头/开灯复现 | 自适应阈值；自动曝光（H5）；演示脚本预置光照 |
| 接长线/换显示器后出错 | 线材质量/显示器兼容性 | 用比赛要求的同款线复测 | 按题目要求用 ≤5 m 纯铜 HDMI 1.4 线调试 |
| 拷到另一块板上不出图 | 器件批次/引脚差异 | 对比两块板现象 | 检查约束是否依赖具体引脚；时序余量是否足够 |

### 3.4 工具与流程类故障

| 现象 | 原因 | 解决 |
|---|---|---|
| 综合报大量位宽不匹配警告 | 隐式位宽转换 | 逐条改为显式 `[n:0]` 截取或扩展，清零或说明理由 |
| 综合报 latch 推断 | 组合 `always` 里有分支未赋值 | 所有分支都给默认值，或改为时序逻辑 |
| 综合报组合环 | 组合逻辑互相依赖 | 打断环，插入寄存器 |
| 时序不收敛（WNS < 0） | 逻辑级数太深 / 扇出太大 / 布线拥塞 | 关键路径插流水线；复制高扇出寄存器；降低算法并行度 |
| 布局布线后功能变了（仿真对、板上错） | 未约束时钟 / CDC 未处理 / 复位不同步 | 补齐约束；排查 CDC |
| 仿真通过但板上完全没反应 | 引脚约束错 / 时钟没进 / 复位一直有效 | 先做最小系统（一个 LED）验证下载链路 |
| IP 例化后编译报错 | IP 版本与器件不匹配 | 用同版本 TD 重新生成 IP |
