### 1.7 《lab_ex_2.docx》—— 边缘检测（**注意：这是你不能照抄的算法**）

- 例程 2 = 例程 1 + **`edge_detect_96`**；分辨率标注 1024×600；ISP 链路 `demosaic(BGGR) → AWB → edge_detect_96`；支持按键调曝光
- **算法细节（文档版）**：RGB 求平均灰度化 → 滑动平均降噪 → Sobel 3×3 求 Gx/Gy → **幅值近似 `mag = |Gx| + |Gy|`**（避免开方）→ 阈值判决 → **多数表决滤波**去孤立噪点 → 边缘白、背景黑
- 模块接口：`I_tdata[95:0]`（**4 像素 RGB888**）、`I_tvalid/tlast/tuser/tready`；`O_tdata[95:0]`
- 参数表：IMG_WIDTH 1024、IMG_HEIGHT 600、**EDGE_TH 132**
- **"内部使用 block RAM 缓存两行灰度数据，实现 3×3 窗口运算"**
- 特性：96-bit 并行像素流、灰度化+滑动平均降噪、Sobel 梯度+幅值近似、阈值可配置、多数滤波

### 1.8 《lab_ex_3.docx》—— OSD 叠加

- 例程 3 = 例程 1 + **OSD**（ISP 链路不含边缘检测）；数据流 `MIPI→ISP(demosaic→AWB)→DDR2→uivtc→hdmi_mixer(+OSD)→hdmi_tx→HDMI`
- OSD 原理：图层分离 → 坐标判决是否属于 OSD 区域 → 非 OSD 直接输出，OSD 区按 **`输出 = OSD像素×Alpha + 视频像素×(1−Alpha)`**（Alpha 0~255）混合 → 边缘抗锯齿 → 与同步时序对齐输出
- `hdmi_mixer` 参数：IMG_WIDTH 1024、IMG_HEIGHT 600、H_OFFSET/V_OFFSET 0、DEBUG_MODE 0
- **`osd_char_lib` 模块提供 Logo 位图与字符点阵 ROM，按 `S_logo_addr` 输出 25-bit 像素（最高位为透明度）**
- 预期现象：**左上角 160×160 显示 Logo；画面中部偏左（约 375,120）显示"安路 CNT:"及递增帧计数**

**g) 帧缓存映射（`video_in.v` / `video_out.v`）**

- **4 个帧缓存**：`IMAGE_BASE_ADDR_0..3 = 0 / 7,000,000 / 14,000,000 / 21,000,000`（地址单位 16 bit → **每帧 14 MB，共 56 MB ≤ 64 MB**）
- 写指针 `wp`；读指针 **`rp = wp + 2 (mod 4)`** → **三缓冲**语义（读落后 2 帧）
- **突发长度 240 拍 × 128 bit = 3840 字节 = 1280 像素 × 3 字节 = 整行 RGB888**
- **MIPI 错误容错（内置）**：`I_mipi_rx_error` 有效时**不推进写指针**，且把下一帧仍写回上一帧的缓冲区（覆盖损坏帧）→ 掉帧不撕裂
- DDR 仲裁：写只在 `!video_out_rd_busy` 时启动，读只在 `!video_in_wr_busy` 时启动（**互斥，非并发**）
- **源码注释记录了一个真实踩坑**："With a continuous 1080p stream that kept wr_busy permanently asserted and starved video_out, so no DDR read request could ever start." → **1080p 连续流下写通路会饿死读通路**（厂商已修，但说明这是本架构的已知风险点）
- FIFO 深度 512（实际可用 510），注释警告**单次突发不要达到 256**，且余量需 > 突发长度 + DDR 读延迟（~10-20 拍）

**h) 帧缓存→像素的位拼接（`video_out.v`）**
128 bit / 24 bit 非整数，故每 **16 像素 = 384 bit = 3 个 128bit 字** 为一个周期，在该周期的第 0、5、10 拍各读一次 FIFO，并在第 5、10 拍跨字拼接（`{fifo_data_1d[7:0], fifo_data[127:112]}`）。**这是全工程最容易写错的一段。**

**p) AWB 实现细节（源码确证）**
- 把 96 bit 拆成 4 像素，**4 组独立累加器**（按 4 像素块相位分别统计 R/G/B），每帧由 `I_tuser` 清零；**统计窗口是整帧**
- **使用 8 个 48÷32 流水除法器**（divider IP，`level_nu=50`），`numerator={sum_g,16'd0}`，商为 Q16.16 的 G/R、G/B
- 增益 20 bit（复位/帧起始 = `20'h10000` = 1.0，上限 `20'hFFFFF` ≈ 16）
- 合成：`28bit = gain(20b) × R(8b)`，取 `[23:16]`；`R_new[27:24]!=0` 时饱和到 255；**G 通道不加增益**
- **不是整帧闭环**：每个有效周期都重启除法器，取"当时运行均值"配给延迟 50 拍的像素 → 流水线式逐像素自适应，**帧头若干拍统计不可靠**

**q) ISP 反马赛克与色彩**
- `bilinear_interpolation`：邻居和（10bit）除 2/4 用 `>>1/>>2`，**截断不舍入**；`mean[8] ? 255 : mean[7:0]` 饱和；输出 `{8'b0,R,G,B}`（每像素 32 bit，**带 8 bit 零填充**）
- RAW10→RAW8 只取高 8 位（丢低 2 位）
- `BAYER_MODE = "BGGR"`
