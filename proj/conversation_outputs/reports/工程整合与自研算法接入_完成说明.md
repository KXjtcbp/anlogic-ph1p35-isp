**my_algo 的 4 种算法模式**（按键循环切换）：

| 模式 | 内容 | 公式 |
|---|---|---|
| MODE 0 | 原图直通 | 用于现场做"开/关算法"对照 |
| MODE 1 | BT.601 灰度 | `Y = (77R + 150G + 29B) >> 8` |
| MODE 2 | 伪彩热力图 | Y 五段线性映射：蓝→青→绿→黄→红 |
| MODE 3 | 亮度阈值二值化 | `Y > 128 ? 白 : 黑` |

**与参考例程不同源的证据**：官方 `lab2` 参考实现 `isp\edge_detect_96.v` 做的是 Sobel 空间域边缘检测（需要 2 个 640×16 行缓存、`sobel_mag` 函数、`$signed` 运算）；本模块是**纯点运算**（不跨像素、无行缓存、无除法器），算法族、数学形式、资源形态都不同。

**接入位置**（`isp\isp_top.v`）：`demosaic → data128_96 → awb → **my_algo** → data_96bit_to_128bit → video_in → …`

**同时新增的演示能力**：
- 按键 `I_button[1]`（J14，24 MHz 域）实时切换 4 种算法 → 对应「进阶要求：多算法切换与状态显示」

## 五、一份源码级背景（便于你理解改动）

```
SC500CS 摄像头
  → mipi_dphy_rx（2 lane, DPHY0）
  → csi_unpacket_2lane → raw10_unpacket_2lane → uial2axis            (AXIS 40bit RAW10)
  → isp_top: demosaic → data128_96 → awb → ★my_algo★ → data_96bit_to_128bit  (AXIS 128bit)
  → video_in（w128_d512_fifo 跨时钟）→ mc_to_user_interface → ph1p35_324_ddr_wrapper → 片内 DDR2
  → video_out（24bit）→ hdmi_mixer（+ anlogic_logo_rom / osd_char_lib / ★MODE n 状态行★）
  → hdmi_tx → HDMI
```

关键位宽事实（三个文件交叉验证过，**不要改**）：
- `isp_top` 里 `awb`/`my_algo`/`data_96bit_to_128bit` 之间是 **96 bit = 4 像素 × 24 bit**
- 每像素 `{R[7:0], G[7:0], B[7:0]}`
  - `isp\data128_96\data128_96.v:16` `{I_tdata[23:0], I_tdata[55:32], I_tdata[87:64], I_tdata[119:96]}`
  - `isp\edge_detect_96.v:22-25` `pix0=[95:72] … pix3=[23:0]`
  - `isp\data96_128\data96_128.v:96` `{{8'd0},I_tdata[95:72], … ,{8'd0},I_tdata[23:0]}`
- `my_algo` / `edge_detect_96` 的端口方向是**反的**（`I_tready` 是 output、`O_tready` 是 input），这是原例程习惯，不要"纠正"
