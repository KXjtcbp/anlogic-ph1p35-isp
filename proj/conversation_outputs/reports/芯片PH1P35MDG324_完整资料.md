## 一、型号解码（来源：FamilyOverview 第 10–11 页「订购信息／器件命名」）

命名规则：`PH1  P  35  M D G 324  [速度][温度]`

| 字段 | 值 | 含义 |
|---|---|---|
| `PH1` | PH1 | 产品系列 = SALPHOENIX®1P |
| `P` | P | 类型 = 逻辑器件 |
| `35` | 35K | 查找表容量 = 35K LUT |
| `MDG324` | 封装类型 | `M`=15mm 级封装，`DG`=具体封装代号，`324`=**324 个引脚** |
| `324` | 324 pins | 引脚数 |
| 速度等级 | **`-3`（中速）** | 来源：工程文件 `<Speed>-3</Speed>`；FamilyOverview 定义 `3 = 中速`（注：只能确定是「3 中速」，是否写作 `-3` 属工程文件口径） |
| 温度等级 | **待确认** | 命名规则里 `I`=工业级（Tj −40~100 ℃）、`A`=车规级（Tj −40~125 ℃）。本机工程与文档均**未出现**该字母，无法判定 |

完整器件号对照：`PH1P35` 家族包含 `PH1P35MBG484`、`PH1P35MDG324`、`PH1P35MHG324`、`PH1P35MEG324`、`PH1P35MEG324A`。

**同一个 324 封装的三个兄弟型号差异（关键）**：

| 型号 | 封装 | 合封内存 | 内存接口速率 | Max DQ |
|---|---|---|---|---|
| **PH1P35MDG324（本机）** | 15×15mm / 0.8mm pitch | **512 Mb**（x16 SDRAM） | **1066 Mbps** | x16 |
| PH1P35MHG324 | 15×15mm / 0.8mm pitch | 1024 Mb（x16 SDRAM） | 1066 Mbps | x16 |
| PH1P35MEG324 / MEG324A | 15×15mm / 0.8mm pitch | 无 | — | — |

PDF 原文（Datasheet 第 45 页 2.12 节）逐字：
> 「PH1P 系列中 PH1P35MDG324 器件内部合封高速存储器，提供高速存储器接口支持。
> 支持 SDRAM 数据位宽为 16-bit,容量为 512Mb
> 支持突发长度为 BL8 模式
> 支持后台进行延时链校准
> 支持写数据掩码」

**⚠️ 这一点对你很重要**：PH1P35MDG324 是**合封内存（SiP）版本**，它自带 512Mb 高速内存，
走的是 **Integrated Memory Interface（集成内存接口，1066 Mbps）**。
但**本机 lab3 工程用的是 External Memory Interface（外挂 DDR2，800 Mbps）+ 板上独立的 DDR2 颗粒**，
引脚是 `ddr_addr[12:0] / ddr_dq[15:0] / ddr_dm[1:0] / ddr_dqs_p[1:0] / ddr_dqs_n[1:0]` 等板级信号。
这两条路是**不同的物理接口**，不要混用。

## 六、MIPI D-PHY（来源：Datasheet 2.13 节，第 40–42 页）

- PH1P35 集成 **2 组 MIPI 硬核**，每组可设为**输入或输出**，最大 **4 Lane**
- 搭配用户逻辑可配置为 **CSI-2**（摄像头串行接口）或 **DSI**（显示串行接口）
- 支持 **HS（高速）/ LP（低功耗）动态切换**
- **LP 支持双向传输**
- 支持动态 Skew 调节、**自动 Skew 校准**
- 输入输出电气参数可编程配置
- 不用于 MIPI 时，**MIPI 硬核可配置为 LVCMOS 和 LVDS 模式**

**RX 功能单元**：`LS_RX`（LP 接收 / LVCMOS）、`LP_TX`（LP 反向传输，所有数据 Lane 都有，通道 0 线序可与其他通道任意交换）、`HS_RX`（HS 接收 / LVDS，支持 **1:8 和 1:16** 串并转换）、`RT`（输入终端电阻控制）、`Clock Control`、`RX Lane Control`

**TX 功能单元**：`LS_TX`（LP 发送 / LVCMOS）、`LP_RX`（LP 反向接收）、`HS_TX`（HS 发送 / LVDS18，支持 **8:1 和 16:1** 并串转换）、`PLL`（TX 内置专用 PLL）、`Clock Control`、`Tx Lane Control`

## 七、MCU 硬核（来源：Datasheet 2.14 节）

- **RISC-V MCU 硬核 ×1**
- 指令集：**RV32 I/M/A/F/C/P/B**
- **三级流水**设计
- **32KB ICache + 32KB DCache + 16KB DLM**
- 支持 **JTAG 调试**
- 支持快速中断响应和定时器
- 通用外设：**QSPI0/QSPI1、UART0/UART1、GPIO×8、I2C**
- 支持 **DMA**
- 支持 **AHB 和 APB 总线**访问 fabric 逻辑

**MCU 时钟规格（Datasheet 表 3-61，逐字）**：

| 器件 | 时钟 | 性能 | 单位 |
|---|---|---|---|
| PH1P35 | `core clk` | **300** | MHz |
| PH1P35 | `timer clk` | **100** | MHz |
| PH1P35 | `apb clk` | **50** | MHz |

**⚠️ 与你的项目相关**：lab3 工程 `.al` 里的 `<Configurations>` 有 `boot_mode=mspix4`，工程里也登记了 `ip_source/MCU/`（`MCU.v`、`Design.xml`、`MCU.xml`）——但**当前设计并没有真正使用 MCU 硬核**。如果用 MCU，CCLK 就不能复用为普通 I/O（见第三节）。

## 八、存储接口（两条不同的路）

### 8.1 External Memory Interface（外挂颗粒，lab3 走这条）
- 支持 **DDR2 / DDR3 / DDR4**（Datasheet 2.11 节；FamilyOverview 0.6 版曾「删除 DDR4」，1.0 版又「新增 DDR4」→ **版本间有反复，需按最终版确认**）
- 最大位宽 **72-bit**，步进 8 bit，**最大颗粒数 9**
- **只支持 BL8 突发模式**
- 支持 x8、x16 颗粒
- 支持**最大 2 个 Rank**
- 支持**后台延时链校准**
- PH1P35MDG324 的 DDR2 速率 **800 Mbps**，Max DQ Width **x16**

### 8.2 Integrated Memory Interface（合封内存，MDG324 特有）
- 仅 **PH1P35MDG324（512Mb）** 和 **PH1P35MHG324（1024Mb）** 有
- 数据位宽 **16-bit**，速率 **1066 Mbps**
- BL8、后台延时链校准、写数据掩码

## 十四、给本项目的三条直接结论

1. **合封内存是 MDG324 独有的、你还没用上的资源。**
   手册明确 PH1P35MDG324 内部合封 512Mb / x16 / 1066Mbps 高速存储器。
   你现在跑的 lab3 用的是**外挂 DDR2 颗粒**（800 Mbps，占 6/12 个 `ddr_byte`）。
   「Integrated Memory Interface」这条路是否已在本板布通、TD 是否提供对应 IP → **待确认**；
   如果可用，它就是现有 DDR 带宽的替代/补充方案（属于「优化系统性能」类扩展要求）。

2. **真正的约束是 `#slice` 和时序，不是 LUT。**
   剩余 slice 6,364（30%），但 Setup WNS 只剩 **+0.103 ns**。
   加逻辑前先算 slice，加完必须重看 `route.qor`。

3. **硬核资源已所剩不多**：MIPI RX 只剩 1、PLL 只剩 3、DDR byte 只剩 6。
   想「再加一路摄像头」或「再加一个 DDR 控制器」在资源上还有空间，但会同时撞上 I/O Bank 电平和时序，
   风险高于加纯逻辑算法。
