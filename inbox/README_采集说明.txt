【这个文件夹是干什么的】
你把 OBS / Win+Shift+S 截出来的原始图丢进这个文件夹即可，不要在文件名里
写开关状态（写错了就毁了证据）。开关状态、光照、画面内容一律写进同目录的
「采集记录.csv」，我一个批次一个批次地归档 + 分析。

★ 为什么不放工作区根目录：`_capture_chain_fit.py`、`_analyse_newest.py` 这类
  脚本会自动挑「E:\FPGA 下 mtime 最新的 png」，根目录残留旧图会让脚本挑错图。
  这个项目已经因此踩过两次坑。

【硬性要求 —— 每张图都必须满足】
 1. 必须是 OBS 的「完整一帧」，不能裁剪、不能缩放。
    ⇒ 左上角的「安路」Logo 和右上角的 CNT 数字必须在画面里。
       Logo 用来校验采集链（我知道它每个像素的确切 RGB）；
       CNT 用来判断两张图是不是同一次上电、间隔多少帧。
 2. 分辨率 1920x1080（OBS 源截图默认就是），格式 PNG。
 3. 一个批次内，机位/朝向/焦距绝对不能动 —— 只允许改开关和光照。
 4. 每拍一张就往「采集记录.csv」补一行。

【怎么截】
  OBS 里右键「视频采集设备」源 → 「截图(源)」
  默认落在 C:\Users\KX\Pictures\，把它复制/移动到本文件夹即可。
  或者直接把 OBS 预览窗口放到最大，Win+Shift+S 框选整个预览区。

【采完怎么告诉我】
  直接说「inbox 里有 N 张，批次 X 采完了」，我会自己读 CSV + 图。
  如果有拿不准的（比如画面和预期不一样），把那一张的名字单独说一下。
